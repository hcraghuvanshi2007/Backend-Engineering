### NPM Commands 
Useful NPM Commands — Quick Reference

| **Command**               | **Description**                                                 |
|---------------------------|-----------------------------------------------------------------|
| `npm init -y`             | Create `package.json` with default values                       |
| `npm install <pkg>`       | Install package and add it to `dependencies`                    |
| `npm install -D <pkg>`    | Install package and add it to `devDependencies`                 |
| `npm install -g <pkg>`    | Install package globally                                        |
| `npm uninstall <pkg>`     | Remove a package and its `package.json` entry                   |
| `npm update`              | Update installed packages within their specified version ranges |
| `npm list`                | List installed packages in the current project                  |
| `npm list -g`             | List globally installed packages                                |
| `npm outdated`            | Check which installed packages have newer versions available    |
| `npm run <script>`        | Run a script defined in `package.json`                          |
| `npm audit`               | Check dependencies for known security vulnerabilities           |
| `npm cache clean --force` | Clear the npm cache                                             |
